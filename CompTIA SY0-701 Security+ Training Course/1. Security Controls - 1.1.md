# Concept Note: Security Controls (CompTIA Security+ SY0-701)

## 1. Objective
Understand the different categories and types of security controls used in IT and physical environments to protect systems, buildings, people, and data.

## 2. Core Categories of Security Controls
* **Technical Controls:** Controls implemented using technical systems, such as operating system configurations, firewalls, and antivirus software.
* **Managerial Controls:** Controls established through organizational policies, procedures, documentation, and standard operating procedures.
* **Operational Controls:** Controls implemented and executed by people, such as security guards, employee awareness programs, and training sessions.
* **Physical Controls:** Controls that limit physical access to buildings, rooms, or devices, such as fences, locks, badge readers, and guard shacks.

## 3. Security Control Types & Methods
1. **Preventive Controls:** Limit access to a resource and stop events from occurring (e.g., firewall rules, physical identification checks, door locks).
2. **Deterrent Controls:** Discourage attackers or make them think twice, even if they don't completely prevent access (e.g., software splash screens, warning signs, threat of dismissal).
3. **Detective Controls:** Identify and warn when a security breach or anomaly has occurred (e.g., system logs, motion detectors, login report reviews).
4. **Corrective Controls:** Actions taken after an event is detected to reverse the impact and restore operations (e.g., restoring from backups, using a fire extinguisher, calling law enforcement).
5. **Compensating Controls:** Alternative solutions used temporarily or when primary resources are unavailable to manage a security risk (e.g., applying a firewall rule instead of patching vulnerable software, power generators).
6. **Directive Controls:** Direct people toward more secure behaviors through compliance policies, training, or instructional signage (e.g., file storage instructions, "Authorized Personnel Only" signs).

## 4. Why This Matters (Security Perspective)
* **For Defenders:** Security requires a defense-in-depth strategy. Combining technical, operational, and physical controls across all functional types ensures that if a preventive control fails, detective and corrective controls catch the issue.
* **For Certification & Practice:** Security+ exams heavily test the ability to map a real-world scenario or security mechanism to its correct control type and category.

## 5. Lessons Learned
Security controls are flexible and can often span multiple categories depending on how they are implemented. Organizations must continuously evolve their security posture as technologies and operational environments change.
